# Guardião da Chama

Jogo de sobrevivência para navegador: corte lenha, cace javalis, construa o acampamento e defenda a fogueira dos monstros a cada noite.

**Jogar:** https://bernardosalgadinho98-eng.github.io/bernardo-fogueira/

## Como instalar

- **Android (Chrome):** abra o link, toque no menu ⋮ e em "Instalar app" (ou "Adicionar à tela inicial").
- **iPhone / iPad (Safari):** abra o link, toque em Compartilhar e em "Adicionar à Tela de Início".
- **Windows (Edge ou Chrome):** abra o link e clique no ícone de instalar na barra de endereço (ou menu ⋯ → Aplicativos → Instalar este site como aplicativo).

Depois de instalado, o jogo abre em tela cheia e funciona sem internet.

## Controles

- **Toque:** arraste o dedo em qualquer lugar da tela.
- **Teclado:** WASD ou setas para andar, Esc ou P para pausar.
- **Controle (Xbox, PlayStation e outros):** analógico ou direcional para andar, Start para pausar, A para confirmar e B para voltar nos menus.

O Bernardo corta, ataca e coleta sozinho quando está perto de algo.
